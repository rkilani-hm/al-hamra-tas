# M1.1 — Manpower Planning & Headcount (Spec)

## Objective
Budgeted-headcount planning by fiscal year / entity / department / job position, with Kuwaitization target tracking, sitting upstream of M1.2 requisitions (requisitions consume budgeted headcount). Bilingual EN/AR, RTL, RBAC via new key `manpower.manage`. SYSTEM_ADMIN bypasses.

## Data model
- `tas_manpower_plan` — id; fiscal_year int not null; entity_id (fk tas_entity); department_id (fk tas_department); job_position_id (fk tas_job_position); budgeted_headcount int not null default 0; kuwaitization_target_pct numeric check 0..100; status ('draft','active','closed') default 'draft'; notes; +audit +trigger.
- Index on (fiscal_year, department_id). RLS authenticated SELECT; writes via SECURITY DEFINER RPCs.

## New key
`manpower.manage` seeded (area 'manpower') + granted SYSTEM_ADMIN, HR_MANAGER, HIRING_MANAGER.

## RPCs (gate manpower.manage)
- `upsert_manpower_plan(p_id, p_fiscal_year, p_entity_id, p_department_id, p_job_position_id, p_budgeted, p_kuwait_pct, p_notes)` → uuid — insert (p_id null) or update by id; validate status untouched here; audit.
- `set_manpower_status(p_id, p_status)` → void — validate in ('draft','active','closed').
- `list_manpower_plans(p_fiscal_year, p_limit, p_offset)` → table — budgeted + a computed `open_requisitions` (count of active requisitions matching department/position) for utilization. Read open.
- `manpower_plan_detail(p_id)` → jsonb — plan + entity/department/position labels. Read open.
- Migration: 14-digit ts sorts last; RLS+grants; no storage bucket literal; no recursive CTE; idempotent.

## Feature — src/features/manpower
- api.ts (interim loose-cast), types.ts.
- Route `/app/manpower` — list (budget vs open reqs, Kuwaitization %, status) + create/edit dialog (fiscal year, entity/department/position selects from config, budgeted, Kuwaitization target). Sidebar entry.
- Capability gating `manpower.manage`; reads open; loading→disabled; SYSTEM_ADMIN passes.

## i18n
Full `manpower.*` namespace EN/AR (ar key-complete) + nav.manpower.
