# M1.11 — Onboarding & MenaME Handoff (Spec)

## Objective
After pre-boarding completes (M1.10), create an onboarding record and hand the new hire off to the MenaME (MenaITech) HRMS. MenaME is a **dormant adapter** (mirrors M0.4/M0.5 adapter pattern) — real API calls are gated behind `tas_hrms_adapter_config`; until credentials are provisioned the handoff is captured/queued in-app so nothing is lost. Bilingual EN/AR, RTL, RBAC via new key `onboarding.manage`. SYSTEM_ADMIN bypasses.

## Data model
- `tas_onboarding` — one per completed pre-boarding.
  - id; preboarding_id uuid unique (fk); application_id; candidate_id; status ('pending','handed_off','completed','cancelled') default 'pending';
  - mename_employee_ref text; handoff_status ('not_sent','queued','sent','ack','error') default 'not_sent'; handoff_payload jsonb; handed_off_at timestamptz; notes; +audit +trigger.
- `tas_hrms_adapter_config` — provider unique ('mename'), is_enabled bool default false, config_status ('unconfigured','configured') default 'unconfigured', notes, +audit. Seed one 'mename' row (disabled). NEVER stores secrets.
- RLS: authenticated SELECT on both; writes via SECURITY DEFINER RPCs.

## New key
- `onboarding.manage` seeded (area 'onboarding') + granted SYSTEM_ADMIN, HR_MANAGER.

## RPCs (gate onboarding.manage; caller from JWT)
- `start_onboarding(p_preboarding_id)` → uuid — require preboarding.status='completed' else raise; idempotent per preboarding; build handoff_payload (candidate + application + offer summary); insert onboarding 'pending'. audit.
- `handoff_to_mename(p_onboarding_id)` → jsonb — read tas_hrms_adapter_config('mename'); if not enabled set handoff_status='queued' + status stays 'pending' (dormant — will transmit once configured); if enabled set handoff_status='sent', status='handed_off', handed_off_at=now() (dormant stub, no real HTTP). audit; return status jsonb.
- `complete_onboarding(p_onboarding_id, p_mename_ref text default null)` → void — set status='completed', mename_employee_ref, handoff_status='ack'. audit.
- `onboarding_detail(p_id)` jsonb, `list_onboarding(p_status,p_limit,p_offset)` table — reads open.
- Migration: 14-digit ts sorts last; RLS+grants; ON CONFLICT rubric-12; no storage bucket literal; no recursive CTE; idempotent.
