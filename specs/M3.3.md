# M3.3 — Audit & Compliance Reporting (Spec)

## Objective
System-wide audit & compliance reporting over the M0.5 audit store (`tas_audit_log`): aggregate stats + a filterable recent-events report. Complements the per-entity M0.5 AuditTrail. Bilingual EN/AR, RTL. Gated on the EXISTING `audit.view` key. SYSTEM_ADMIN bypasses. No new table, no new key.

## Data access (SECURITY DEFINER, gate audit.view, EXECUTE authenticated)
- `audit_stats()` → jsonb — total, last_24h, by_module [{module_code, count}], by_event [{event_type, count}].
- `audit_report(p_module text, p_limit int, p_offset int)` → table — recent events (id, created_at, actor name, module_code, event_type, entity_type, entity_ref), optional module filter.
- Migration: 14-digit ts sorts last; no storage bucket literal; no recursive CTE; idempotent.

- Route `/app/compliance` — stats cards + by-module/by-event breakdowns + recent audit events table with a module filter. Sidebar entry.
